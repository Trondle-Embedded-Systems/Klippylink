KlippyLink Flasher

Flash your ESP32 devices directly from the browser — no drivers required.

ESP32-S3

Node Firmware

Flash this to any ESP32-S3 that will act as a peripheral node — controlling NeoPixel LEDs, reading endstops, and reporting state to the router over BLE.

After flashing, upload your config.json to the device via the OTA config endpoint or copy it to the SPIFFS partition.

ESP32-C3

Router Firmware

Flash this to the ESP32-C3 that bridges BLE nodes to Klipper. It scans for nodes, maintains connections, and exposes a REST + WebSocket API on port 8765.

After flashing, connect via USB serial and run klippylink-config.py --port /dev/ttyACM0 --ssid … --password … to set WiFi credentials.

First-time setup guide

  1. Flash the router (ESP32-C3) using the button above. Plug it into your computer via USB before clicking.
  2. Configure WiFi on the router — open a terminal and run:
    python3 klipper-extension/klippylink-config.py --port /dev/ttyACM0 --ssid "MyNet" --password "secret"
  3. Flash each node (ESP32-S3) using the "Flash Node" button.
  4. Upload a config to each node — create a config.json (see configs/node_example.json) and POST it to
    http://<router-ip>:8765/api/nodes/<node>/config
  5. Install the Klipper extension on your Pi:
    bash klipper-extension/install.sh
  6. Add the [klippylink] section to your printer.cfg (see klipper-extension/klippylink.cfg.example) and restart Klipper.
