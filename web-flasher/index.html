KlippyLink Installer

Router
ESP32-C3
  1. Plug the ESP32-C3 into USB, then click Install.
  2. Set WiFi credentials once:
    POST http://<router-ip>:8765/api/wifi {"ssid":"…","password":"…"}
  3. Run bash klipper-extension/install.sh on your Pi.
Node
ESP32-S3
  1. Plug the ESP32-S3 into USB, then click Install.
  2. Upload config.json to the node's SPIFFS partition to define its LEDs and endstops.
  3. The router discovers this node automatically over BLE.
